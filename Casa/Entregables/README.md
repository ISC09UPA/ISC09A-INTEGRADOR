# Entregables de Casa Domótica

| Entregable | Rama | Contenido |
|---|---|---|
| 01 — Backend núcleo | `casa/nov13/backend-nucleo` | Identity, Home y Home.Functions. |
| 02 — Backend seguridad | `casa/nov13/seguridad` | Security, Assistant, capturas y Vision. |
| 03 — App móvil | `casa/nov13/movil` | Aplicación Expo completa. |
| 04 — Infraestructura | `casa/nov13/infraestructura` | Contratos, scripts, documentación e integración. |

La base común es `casa/nov13/base`. Cada rama se integra por separado y al final se fusionan en la base.
